---
id: useless-outlet-component
title: Disallow route components that only render `<Outlet />`
---

Declaring a route component that only returns `<Outlet />` is the same as declaring no route component at all — TanStack Router renders the outlet by default when no `component` is supplied. Such components are frequently left over after refactoring or generated by AI tooling. Omitting them reduces unnecessary code and makes routes easier to read.

This rule flags three forms of redundant `component`:

- inline arrow / function expressions whose body is only `<Outlet />` (optionally wrapped in a fragment),
- references to a local function that only returns `<Outlet />`, and
- a direct reference to the `Outlet` value imported from a `@tanstack/*-router` package.

The autofix removes the `component` property entirely. Any local function that becomes unused as a result can be cleaned up by your existing `no-unused-vars` rule.

## Rule Details

Examples of **incorrect** code for this rule:

<!-- ::start:framework -->

# React

<!-- ::start:tabs variant="files" -->

```tsx title="src/routes/path.tsx"
/* eslint "@tanstack/router/useless-outlet-component": "warn" */
import { createFileRoute, Outlet } from '@tanstack/react-router'

export const Route = createFileRoute('/path')({
  component: RouteComponent,
})
  
function RouteComponent() {
  return <Outlet />
}
```

<!-- ::end:tabs -->

# Solid

<!-- ::start:tabs variant="files" -->

```tsx title="src/routes/path.tsx"
/* eslint "@tanstack/router/useless-outlet-component": "warn" */
import { createFileRoute, Outlet } from '@tanstack/solid-router'

export const Route = createFileRoute('/path')({
  component: RouteComponent,
})

function RouteComponent() {
  return <Outlet />
}
```
